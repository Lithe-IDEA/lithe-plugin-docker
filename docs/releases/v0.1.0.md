## 中文

Docker for Lithe 首个公开版本，在 Lithe 工具窗口中管理本机容器、镜像、卷和网络。

### 下载与安装

- [macOS 安装包（Apple silicon / Intel 通用）](https://github.com/Lithe-IDEA/lithe-plugin-docker/releases/download/v0.1.0/docker-0.1.0-darwin.zip)
- [SHA-256 校验文件](https://github.com/Lithe-IDEA/lithe-plugin-docker/releases/download/v0.1.0/docker-0.1.0-darwin.zip.sha256)

在支持插件 `backend:2`、Web UI 和 `browser.open` 的 macOS 版 Lithe 中，打开「设置 → 插件 → 从磁盘安装」，选择 ZIP。启动 Docker Desktop、OrbStack、Colima 等本机引擎后使用。已有本地试用包的用户请重新导入此 Release 的 ZIP。

### 功能

- 容器按 Compose 项目分组，显示实际配置文件路径，支持筛选、启动、停止、重启、暂停、恢复、终止与删除。
- 镜像、卷、网络及磁盘用量集中查看，支持拉取镜像、从镜像创建容器和确认后清理未使用资源。
- 详情使用分组卡片和斑马纹表格，显示实际端口、挂载、网络、选项与完整标签。
- 日志支持搜索、跟随、时间戳、换行、横向滚动与复制；正文使用主题文字色，时间戳为灰色，HTTP(S) 链接为蓝色。
- 检查结果、进程 JSON 和完整 JSON 日志行使用语法高亮，链接可交给系统浏览器打开。
- CPU、内存、网络速率和磁盘速率以四张图显示，采样间隔可选 1、2、5、10 秒，不显示历史采样表。
- 容器文件页可浏览目录、拖入普通文件上传、通过原生对话框选择上传文件并下载选定文件，同名替换前先确认。
- 导航栏、详情面板与表格列宽支持拖动和键盘调整，窗口自适应，保留用户布局与采样间隔。
- 支持中英文和明暗主题，优先读取 Docker Hub Logo，并为部分公开镜像补充随包品牌图标。
- 跟随 Docker CLI 的真实连接配置，也可显式保存本插件的 context 或 Unix socket 选择，不改写 Docker CLI 配置。

### 兼容性与已知限制

- 当前仅支持 macOS，本版本不包含 Windows 插件。
- 此包未附带 Lithe 发布者签名；安装时请核对来源、校验值和宿主显示的权限。后端包含本地 ad hoc 签名，不代表发布者认证。
- 文件浏览要求容器运行中，并提供 `/bin/sh` 和兼容 `stat -c` 的工具；单文件上限 256 MiB，单目录上限 5,000 项。
- 暂不支持文件夹传输、拖出到 Finder、交互式终端、镜像构建、私有仓库登录、SSH/TLS/TCP 远端或 Dev Containers。
- Compose 分组动作只操作已存在的容器，不执行 `docker compose up/down`，不应用 YAML 配置或编排依赖。
- 本地验证包括类型检查、前后端测试、真实 Core＋Docker 文件往返和包文件不变性，以及浏览器预览上传下载；Lithe 原生文件对话框、系统浏览器实际启动和 Finder 拖入仍需目标宿主验收。
- 图表采样只保留在内存中；运行时状态和 Logo 缓存写入宿主提供的可写目录，安装包保持只读。

## English

The first public release of Docker for Lithe manages local containers, images, volumes and networks inside a Lithe tool window.

### Download and install

- [macOS package (universal Apple silicon / Intel)](https://github.com/Lithe-IDEA/lithe-plugin-docker/releases/download/v0.1.0/docker-0.1.0-darwin.zip)
- [SHA-256 checksum](https://github.com/Lithe-IDEA/lithe-plugin-docker/releases/download/v0.1.0/docker-0.1.0-darwin.zip.sha256)

Use a macOS Lithe host supporting plugin `backend:2`, Web UI and `browser.open`. Choose the ZIP in Settings → Plugins → Install from Disk, then start a local engine such as Docker Desktop, OrbStack or Colima. Replace earlier local trial packages by importing this release's ZIP.

### Features

- Group containers by Compose project, show recorded configuration paths, filter resources, and start, stop, restart, pause, resume, kill or remove containers.
- Browse images, volumes, networks and disk usage, pull images, create containers from images, and prune unused resources after confirmation.
- Inspect actual ports, mounts, networks, options and complete labels through grouped cards and alternating table rows.
- Search, follow, timestamp, wrap, horizontally scroll and copy logs, with theme-colored text, gray timestamps and blue HTTP(S) links.
- Highlight inspection JSON, process JSON and complete JSON log lines, and open web links through the system browser.
- Display CPU, memory, network and disk rates in four charts, with selectable 1, 2, 5 or 10 second sampling and no historical sample table.
- Browse container directories, upload dropped regular files or files selected through the native dialog, and download selected files, with confirmation before replacing a same-name file.
- Resize navigation, details and table columns by pointer or keyboard; adapt to the window and retain layout and sampling preferences.
- Follow English or Chinese and light or dark appearance, prefer Docker Hub logos, and supplement selected public repositories with bundled brand icons.
- Read the real Docker CLI connection configuration or save an explicit plugin-only context or Unix socket without changing Docker CLI configuration.

### Compatibility and known limitations

- This release supports macOS only and does not include a Windows plugin.
- The package has no Lithe publisher signature. Check the source, checksum and permissions shown by the host before installation. The backend's local ad hoc signature is not publisher authentication.
- File browsing requires a running container with `/bin/sh` and compatible `stat -c`. Regular files are limited to 256 MiB and directories to 5,000 entries.
- Folder transfers, dragging files out to Finder, interactive terminals, image builds, private registry sign-in, SSH/TLS/TCP remote engines and Dev Containers are not supported yet.
- Compose group actions operate on existing containers; they do not run `docker compose up/down`, apply YAML changes or orchestrate dependencies.
- Local checks cover type checking, frontend/backend tests, real Core＋Docker file round trips and package immutability, and browser-preview uploads/downloads. Native Lithe file dialogs, actual system-browser launch and Finder drag-in still require target-host acceptance.
- Chart samples stay in memory. Runtime state and logo caches use host-provided writable storage; the installed package stays read-only.
